## Session-discovered bugs
- **[2026-07-07] [agents] Physics Dijkstras hardcoded to the NCR graph + KeyError on unreachable destinations** — `surgical_agent._dijkstra_physics_fallback` and `swarm_agent._dijkstra_with_hive_weights` ignored the swarm's injected graph (routed on `_DEFAULT_NODES/_DEFAULT_EDGES`) and did `dist[destination]` (KeyError when the destination isn't in the node set or is unreachable via one-way dead ends). Fix: optional `nodes`/`edges` params threaded from the swarm's `state` dict + `dist.get(..., inf)` guards + origin/destination membership checks. Regression: `tests/engines/agent_simulation/test_injected_graph.py::test_physics_timestep_routes_on_injected_graph`. — **status: fixed 2026-07-07.**
